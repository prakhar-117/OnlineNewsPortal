# 📰 The Daily Brief — Online News Portal

A clean, responsive news portal built using **HTML5, CSS3, and JavaScript**. The Daily Brief provides an organized way to explore headlines, browse news categories, discover trending stories, and subscribe to a newsletter.

## ✨ Features

- **Featured Headlines** — A dedicated section highlighting the main story.
- **Latest Articles** — Article cards covering different topics.
- **News Categories** — Explore India, World, Technology, Business, Sports, and Science.
- **Trending Stories** — A dedicated section for popular stories.
- **Newsletter Subscription Form** — Enter your name, email address, and preferred news category.
- **Form Submission Feedback** — Basic JavaScript displays the submitted details and a success message.
- **Responsive Layout** — CSS Grid, Flexbox, and media queries help the website adapt to different screen sizes.
- **Custom Branding** — A CSS-designed logo and a consistent visual theme.

## 🛠️ Tech Stack

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, animations, and responsive design.
- **JavaScript** — Basic form submission handling and displaying user-entered details.

## 🚀 Getting Started

You can run this project locally without installing any additional software.

1. Clone the repository:

   ```bash
   git clone https://github.com/prakhar-117/OnlineNewsPortal.git
   ```

2. Open the project folder:

   ```bash
   cd OnlineNewsPortal
   ```

3. Open `index.html` in your web browser.

You can also open the folder in Visual Studio Code and use the Live Server extension for convenient development.

## 🎯 Project Objective

The objective of this project is to practise front-end web development by building a structured, visually appealing, and responsive website. It demonstrates the use of semantic HTML, reusable CSS classes, Flexbox, CSS Grid, media queries, and basic JavaScript DOM manipulation.
